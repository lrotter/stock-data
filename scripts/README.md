# Scripts Directory

This directory contains bash scripts for the stock-data project.

## Usage

All scripts should be executable and follow these guidelines:

1. Save output to the `../data/` directory
2. Use timestamps in output filenames for tracking
3. Include proper error handling
4. Add comments to explain script functionality

## Example

Run the example script:

```bash
cd scripts
./example.sh
```

This will create a timestamped output file in the `data` directory.
