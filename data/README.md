# Data Directory

This directory contains the results of script executions from the `scripts` directory.

## Purpose

Scripts in the `scripts` directory will save their output and results here. These results are committed to the repository for tracking and analysis.

## File Naming Convention

It's recommended to use timestamps in filenames to track when data was generated:
- Format: `<description>_YYYYMMDD_HHMMSS.txt`
- Example: `stock_data_20240101_120000.txt`
